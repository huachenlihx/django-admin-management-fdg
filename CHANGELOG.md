## 1.0.0

First public stable release; consolidates the earlier development versions.

- Declarative model-level and object-specific buttons, protected management pages and endpoints.
- Template, custom callable and existing named URL modes (existing URLs are model-scoped only).
- Scoped permissions, Admin navigation, grouped sibling links and optional confirmation.
- Endpoint URL tag, fetch helpers, dashboard partials and opt-in endpoint audit logging.
- Standalone demo, 15 bundled tests, scope guide, template usage guide and integration documentation.
- Django dependency is `Django>=5.2` without an upper bound; newer versions require compatibility verification.
- Release metadata updated and distributions rebuilt; see VALIDATION.md for test coverage and limitations.
